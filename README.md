# Library Management System [SIMPLIFIED]

A simple fucking library system built with **PHP, MySQL, HTML, CSS, and JavaScript**. Originally made as a school project to practice basic CRUD, database operations, users, books, and borrowing. Basically, books go in, books go out, PHP suffers.

**Project Status:** SUPER SIMPLIFIED / SCHOOL PROJECT

### What This Shit Can Do

The system handles the basic library flow: **manage books, manage users, borrow books, return books, and keep basic records**.

Nothing complicated. No giant feature list. Just the core shit needed for a simple library system.

### Tech Stack

**PHP, MySQL, HTML, CSS, JavaScript, and XAMPP.**

PHP handles the backend, MySQL handles the data, and HTML, CSS, and JavaScript handle the interface.

### About

This is a simplified version of an old school project, kept small and straightforward instead of turning it into another fucking enterprise system.

Simple library. Simple CRUD. Simple PHP.

That's it.
